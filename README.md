# ECS · Entrepreneurship Club Sapir

Landing page prototype for the Entrepreneurship Club at Sapir College.

- Hebrew (RTL) by default, English (LTR) through the header switch
- Plain HTML, CSS and JavaScript, no build step
- Open `index.html`, or serve the folder with any static server

Photos are from Unsplash. Team members, partners, project stories and figures are illustrative.
The join form, WhatsApp invitation, event registration and contact links are demo placeholders until they are connected.
